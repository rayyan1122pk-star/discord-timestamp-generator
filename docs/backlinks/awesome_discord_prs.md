## 3. Reddit Community Post (`r/Discord_Bots`)
- **Subreddit:** `https://reddit.com/r/Discord_Bots`
- **Post Flair:** `Tool / Resource`
- **Post Title:** `I built a free, privacy-first Discord timestamp & embed generator with live chat preview`
- **Post Body:**
```markdown
Hey everyone,

Whenever I was scheduling international gaming tournaments across different timezones, members constantly missed events due to UTC offsets. While Discord has `<t:TIMESTAMP:STYLE>` dynamic tags, generating the Unix epoch math and testing embed layouts was always cumbersome.

I built **[DiscTimestamps](https://www.disctimestamps.site)** as a completely free, 100% client-side developer utility.

Key features:
- **Timestamp Generator:** 1-click copy for all 7 styles (`:R`, `:f`, `:F`, etc.) with real-time Discord chat preview.
- **Discord Embed Builder:** Live dark-mode preview card with 1-click export to Webhook JSON (auto-converts hex colors to 24-bit decimal integers), discord.js v14 `EmbedBuilder`, and discord.py.
- **Snowflake Decoder:** Paste any User ID, Message ID, or Server ID to view exact creation timestamp.
- **ANSI Colored Text Maker:** Visual picker for Discord ANSI codeblocks.
- **Glitch / Zalgo Font Maker:** Nickname-safe combining diacritical marks generator.

The entire project is open-source on GitHub: https://github.com/rayyan1122pk-star/discord-timestamp-generator

Feedback and feature requests are very welcome!
```

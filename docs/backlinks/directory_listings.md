- **Website URL:** https://www.disctimestamps.site
- **Categories:** Developer Tools, Open Source, Productivity, Discord
- **Description:**
  Discord Timestamps is an ad-free, 100% in-browser utility for Discord moderators, event hosts, and bot developers.
  
  Features:
  - Generate dynamic <t:TIMESTAMP:STYLE> tags that automatically adjust to every user's local timezone
  - Live Discord chat preview with hover tooltips
  - Natural shorthand input ("tomorrow at 5pm", "in 2 hours", "tmr 6 pm")
  - Reverse tag decoder: paste any Discord tag or Unix epoch to inspect date and countdown
  - Discord Snowflake ID to timestamp decoder
  - Discord ANSI colored code block editor
  - Zero tracking, zero ads, zero external API dependencies

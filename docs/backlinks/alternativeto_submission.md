### Description (Copy & Paste)
Discord Timestamps (https://www.disctimestamps.site) is a fast, lightweight, and completely ad-free web utility built for Discord server moderators, event hosts, and bot developers.

When you post events or announcements in Discord, typing static times like "8 PM EST" confuses international members. Discord supports dynamic timestamp tokens (<t:TIMESTAMP:STYLE>) that automatically convert to each viewer's local device clock.

Key Features:
1. Live Discord Chat Preview: See how your timestamp renders in dark mode with real-time hover tooltips.
2. All 7 Discord Flags: 1-click copy for Relative (:R), Short Time (:t), Long Time (:T), Short Date (:d), Long Date (:D), Short Date/Time (:f), and Long Date/Time (:F).
3. Quick Shorthand Parsing: Type phrases like "tomorrow at 5pm", "in 2 hours", or "tmr 6 pm" for instant epoch math.
4. 100% Client-Side Privacy: All calculations run locally in your browser using native JavaScript Intl APIs. Zero tracking scripts, zero ads, zero data transmission.
5. Reverse Timestamp Decoder: Paste existing <t:...> tokens or raw Unix epochs to see their exact date and countdown.
6. Snowflake ID Converter: Extract account and message creation dates directly from Discord 64-bit Snowflake IDs.
7. ANSI Colored Text Builder: Generate colorful code blocks with custom ANSI foreground and background colors.

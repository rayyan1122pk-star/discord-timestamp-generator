# Programmatic SEO Policy & Anti-Spam Gate

**Target Website:** https://discord-timestamp-generator-swart.vercel.app/  
**Objective:** Maintain high topical quality and protect against Google Helpful Content and Scaled Content Abuse penalties.

---

## 1. Absolute Prohibitions

The following programmatic patterns are strictly prohibited on this website:
1. **City / Geo-Location Spin:** Never create pages like `/discord-timestamp-generator-london` or `/discord-timestamp-generator-tokyo`. The core tool already auto-detects all timezones dynamically. Creating localized URLs without unique content constitutes thin doorway spam.
2. **Game-Specific Spin:** Never create automated pages like `/discord-timestamp-for-minecraft`, `/discord-timestamp-for-roblox`, or `/discord-timestamp-for-valorant` that simply swap the game title in a template. Discord timestamp syntax is identical across all games and servers.
3. **Keyword-Stuffed Synthetic Text:** Every page must contain manually reviewed, technically accurate explanations with verifiable code snippets.

---

## 2. The Programmatic Quality Filter

A new programmatic page type is only authorized if it satisfies all four criteria:
* **Unique Computational Value:** The page performs a distinct mathematical or lexical calculation that cannot be solved by the general homepage.
* **Information Gain:** The page provides distinct documentation, edge-case analysis, or code examples specific to that input.
* **Search Intent Differentiation:** Real users search for that specific technical concept with distinct requirements.
* **Maintenance Feasibility:** The data can be programmatically verified against regressions in CI.
